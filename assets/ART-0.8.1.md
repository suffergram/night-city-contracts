# Anatomical aim poses / 0.8.1

Generated with the built-in `image_gen.imagegen` tool; transparent RGBA backgrounds.
Final asset: `characters/mercenary-aim-extremes-v2.png`.
Initial generation used `characters/mercenary-aim-rig-v1.png` as the identity/material reference.
The subsequent edit used `characters/mercenary-aim-extremes-v1.png` as its edit target to
restore complete barrels and provide padding inside cells. Sources are preserved unchanged.

## Frame layout

Six columns by six rows. Columns contain three raised-gun and three lowered-gun poses.
Rows 0/1: pistol ready/recoil; rows 2/3: rifle ready/recoil; rows 4/5: shotgun ready/recoil.
The shoulder remains upright while elbows and support hands change posture for each angle.

For elevations from horizontal through 45 degrees upward, the existing arm layer remains active.
Above that range and for downward aiming, `src/aim.js` selects a bent-elbow pose and applies
only a small angle correction. Registered shoulder and barrel-tip metadata lives in
`src/aim-pose-data.js`. The same transform drives visible gun, muzzle flash and projectile origin;
all thirteen requested firing directions remain available. No visual-only angle clamp is used.
The existing complete reload, katana, block and roll clips remain active for their actions.

Scale correction: the additional pose layer uses 0.62 of the body cell width, calibrated to
the horizontal sleeve/shoulder thickness. Total silhouette bounds include the weapon and
must not be used to match arm size. Muzzle registration uses this same scale.

Material correction: every cell of the extreme-pose atlas, and rows 4–5 of the original aim
rig, contains arms only. Jacket fabric can inherit the torso material across the whole cell;
helmet, trousers and boot masks must never recolour these cells. Chrome and weapon shading
retain their original neutral tones. Browser checks compare rendered pixels after changing
head/legs/feet gear while keeping the same jacket.

Visual review: `../artifacts/night-city-aim-gallery.png` generated by `scripts/browser-check.mjs`.
