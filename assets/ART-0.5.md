# Raster artwork / version 0.5

Generated using the built-in `image_gen.imagegen` tool. No CLI, API key or imported Cyberpunk game assets were used.

Final workspace assets:

- `assets/characters/mercenary-actions-v1.png`: 6 × 6 transparent action atlas; rows: backpedal, running katana, running fire, backpedal fire, airborne katana, airborne fire.
- `assets/characters/weapons-v1.png`: 2 × 2 transparent weapon art; katana, pistol, rifle, shotgun. Used by HUD and long-gun overlays.
- `assets/environment/city-v1.png`: opaque painted city panorama for scrolling backdrop.
- `assets/environment/props-v1.png`: 4 × 3 transparent modular prop atlas; safehouse, arms dealer, ripperdoc, med terminal; extraction gate, catwalk, crate, lamp; road strip, vent tower, AC/barrels, pipes.

The renderer reads actual source dimensions. The requested resolutions in the prompts need not equal the tool's delivered sizes. Sources are copied into this project and are not rewritten by runtime colour/material variations. Character action generation used `assets/characters/mercenary-clean-v1.png` as an identity/style reference; the other three images were new generations.
