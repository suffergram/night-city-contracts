## Prompt specification

Use case: stylized-concept. Production transparent 2D side-scroller animation atlas.
Use the supplied mercenary as the identity and painted-style reference: short black hair,
cyan eye implant/collar, oxblood armored jacket, chrome forearm, graphite trousers and heavy shoes.
Six equal columns and rows, full-body right-facing side views, identical scale and bottom-center
anchor. Weapons and limbs must fit inside each cell. No grid, labels, scenery, shadows, muzzle
flashes, sparks, bullets, smoke or fire. These are movement/reload animations, not shooting.

Utility atlas: six connected poses per row, following the first table. The first row attacks
to the right while stepping backwards to the left. Reload rows include magazine removal,
replacement, insertion and racking, combined with standing, forward/backward strides, or
ascent/apex/descent. The last row holds a pistol ready in the air without firing.

Long-gun atlas: follow the second table. Rifle hands operate the magazine and bolt; shotgun
hands retrieve/feed a shell and pump. Running poses cycle the legs; airborne poses tuck the
knees. The last two rows hold the corresponding weapon ready without firing.

## Runtime integration

Final long-gun generation prompt (verbatim):

```text
Use case: stylized-concept. Production sprite atlas for a 2D side-scroller. Reference image sets the same mercenary identity and realistic painted cyberpunk style: male black hair, red armored jacket, cyan collar, chrome forearm, dark pants. Transparent RGBA, 6 columns x 6 rows, square 1536px. All 36 full-body figures face RIGHT, consistent scale centered in equal 256px cells, feet baseline 238px. No grid, labels, scenery, flash, fire, smoke or sparks. Exact row layout: row1 cells1-3 standing assault rifle reload removing magazine, inserting, bolt; cells4-6 forward RUNNING rifle reload with cycling legs. Row2 cells1-3 backward RUNNING rifle reload (faces right, steps left), cells4-6 airborne rifle reload ascent/apex/descent. Row3 cells1-3 standing shotgun reload retrieving shell, loading shell, pumping; cells4-6 forward RUNNING shotgun reload. Row4 cells1-3 backward RUNNING shotgun reload; cells4-6 airborne shotgun reload ascent/apex/descent. Row5 six airborne rifle-ready poses, NO SHOOTING. Row6 six airborne shotgun-ready poses, NO SHOOTING. Weapon must be clearly a rifle or shotgun, no pistol. Hands interact with magazine/shell while reloading. Ground running rows have distinct leg strides; airborne rows have knees tucked. Keep each complete figure and gun inside its cell. Match reference detail, anatomy and costume.
```

`src/animation.js` selects complete authored poses for each movement context. Standing reload
frames follow actual reload progress, moving reloads cycle with stride time, airborne poses
follow vertical velocity. Changing movement does not restart the gameplay reload timer.

Katana frames follow the remaining attack timer across direction and airborne transitions.
The backward strike contacts at 0.21 seconds, matching its cutting pose. Other strikes retain
their existing contact time. Firing visuals have their own brief timer instead of lasting for
the whole weapon cooldown; non-firing jump/landing poses use clean atlases.
